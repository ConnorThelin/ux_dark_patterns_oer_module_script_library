UX Deceptive Patterns OER Module Abstract
UX Deceptive Patterns are defined by the U.S. Federal Trade Commission as “design practices that trick or manipulate users into making choices they would not otherwise have made and that may cause harm”. Though common, few students learn to identify these patterns. "An Evidential Exploration of Deceptive UX Patterns" is an educational module in which students apply UX research methods to identifying problematic patterns in everyday life.  

This capstone project focused on working with Dr. Dharma Dailey to transform the module into an Open Educational Resource that computer science and data science instructors can deploy in their own classrooms even if they lack expertise  in HCI theory and UX research methods.

Our improvement process centered on expert evaluations of core module components targeted sampling for complementary expertise: UX practitioners and educators, data science practitioners and educators, OER experts, as well as academic researchers, government analysts, and public scholars who address deceptive patterns. These experts helped us to validate or improve core module components such as the supporting readings, data collection instrument and procedures, student analysis activities, student outputs, and new script library that supports educator and student workflows.

I helped plan and execute the 10 expert evaluations; created and iterated on an example of student work used in the evaluations; To more reliably transform raw survey data into usable classroom data, a ~900 line R script library was developed with a supporting walkthrough document and systems diagrams.

In this way, I helped refine the original project’s core learning objectives, lesson plans, and data workflow while making substantive progress to deploy an OER version of this module.
